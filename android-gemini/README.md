# Gemini Glasses (Android)

Phone app that uses Meta's Wearables Device Access Toolkit (Developer Mode, app id "0") to take a photo with
your Ray-Ban Display glasses, ask Gemini about it, and show the answer on the lens (also spoken on the phone).

Setup: Meta AI app → Settings → App Info → tap version 5x → enable Developer Mode. Install the APK, paste a free
Gemini API key (aistudio.google.com), tap Register, then Connect glasses, then pinch "Ask" on the lens.
The key is stored only on the phone. Build: GitHub Actions "Build Gemini Glasses APK".
